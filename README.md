# Keyboard Familiarizer
Keyboard Familiarizer v0.1 Alpha

**Learn the keyboard first. Learn to type second.**

Keyboard Familiarizer is a simple keyboard geography trainer designed to help users build a mental map of the keyboard before focusing on typing speed.

Most typing trainers concentrate on words per minute and traditional touch-typing exercises. Keyboard Familiarizer takes a different approach: learn where the keys are, become comfortable navigating the keyboard without looking, and build consistent muscle memory through focused spatial drills.

## Why Keyboard Familiarizer?

Keyboard Familiarizer started with a simple problem:

> After years of using a keyboard, I could type—but I still wasn't completely familiar with the keyboard itself.

Traditional typing practice didn't quite address that problem. The goal here is to practice the keyboard as a physical layout rather than immediately concentrating on odd letter combinations, words and speed.

## How to Use

### Online

Open the Keyboard Familiarizer GitHub Pages site and start typing.

### Offline

Download `index.html` and open it in any modern web browser.

No installation, account, or internet connection is required.

## Project Philosophy

Keyboard Familiarizer is **not intended to be another typing-speed test**.

The project focuses on the step that often gets overlooked:

**Keyboard familiarity → muscle memory → touch typing → speed**

Future drills will continue to focus on keyboard geography and spatial familiarity rather than simply measuring words per minute.
